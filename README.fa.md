# Sensor Lock

Sensor Lock یک ابزار متن‌باز اندروید برای کنترل حریم خصوصی دوربین و میکروفون است که توسط ELUQEN توسعه داده شده است.

برنامه می‌تواند دوربین و میکروفون را در سطح سیستم مسدود یا آزاد کند، وضعیت واقعی هرکدام را جداگانه بررسی کند، در صورت متفاوت بودن وضعیت آن‌ها حالت Mixed را نشان دهد و همان کنترل را در Quick Settings در اختیار کاربر قرار دهد.

## سازگاری

برای گوشی‌ها و تبلت‌های Android 11 و بالاتر طراحی شده است.

- Root لازم نیست.
- زبان‌های فارسی، انگلیسی و فرانسوی دارد.
- Quick Settings tile دارد.
- معیار اصلی سازگاری نسخه اندروید است.
- بعضی ROMهای اختصاصی ممکن است رفتار Wireless debugging یا بازیابی را تغییر دهند.

## چرا بار اول Wi-Fi لازم است؟

Android اجازه کنترل مستقیم این بخش از Sensor Privacy را به یک برنامه عادی نمی‌دهد.

Sensor Lock در راه‌اندازی اول از Wireless debugging خود Android استفاده می‌کند تا روی همان دستگاه یک سرویس محلی با سطح دسترسی لازم ایجاد کند.

اینترنت لازم نیست، اما Android برای Wireless debugging هنگام Pairing نیاز دارد دستگاه به یک شبکه Wi-Fi متصل باشد.

بعد از راه‌اندازی موفق، استفاده عادی تا وقتی سرویس محلی فعال است به Wi-Fi یا اینترنت نیاز ندارد.

## راه‌اندازی اولیه

1. گوشی یا تبلت را به Wi-Fi وصل کنید. اینترنت لازم نیست.
2. اگر Developer options مخفی است، آن را فعال کنید.
3. مسیر متداول: Settings → About phone/tablet → Software information → Build number.
4. روی Build number هفت بار بزنید.
5. Sensor Lock را باز کنید و وارد راهنما و آموزش اتصال شوید.
6. شروع Pairing را بزنید. برنامه ابتدا Pairing را فعال می‌کند و بعد Wireless debugging را باز می‌کند.
7. Wireless debugging را در صورت نیاز روشن کنید.
8. روی Pair device with pairing code بزنید و صفحه را باز نگه دارید.
9. اعلان Sensor Lock را باز کنید.
10. پیدا کردن پورت Pairing را بزنید.
11. کد ۶ رقمی اندروید را وارد کنید.
12. بعد از تکمیل اتصال، اعلان Pairing خودکار حذف می‌شود.

## استفاده عادی

- Protect هر دو حسگر را مسدود می‌کند.
- خاموش کردن محافظت هر دو را آزاد می‌کند.
- Check protection وضعیت واقعی را بررسی می‌کند.
- Quick Settings tile همان کنترل را بدون باز کردن برنامه انجام می‌دهد.
- دوربین و میکروفون جداگانه بررسی می‌شوند.

### حالت Mixed

ممکن است Android یا رویدادی مثل تماس فقط وضعیت یکی از حسگرها را تغییر دهد.

Sensor Lock این وضعیت را پنهان نمی‌کند. اگر یکی مسدود و دیگری آزاد باشد، Mixed نمایش داده می‌شود. با Protect دوباره تلاش می‌شود هر دو مسدود شوند.

## ریبوت و بازیابی

بعد از ریبوت یا اگر Android سرویس محلی را متوقف کند، Sensor Lock تلاش می‌کند اتصال را خودکار بازیابی کند. اگر موفق نشود، اعلان اتصال مجدد نمایش داده می‌شود.

بعد از اتصال موفق، Notification دائمی Connected باقی نمی‌ماند.

## مجوزها

- WRITE_SECURE_SETTINGS: مدیریت تنظیمات موقت راه‌اندازی و Recovery.
- INTERNET: فقط برای سوکت محلی ADB/TLS هنگام Pairing یا Repair؛ برنامه Backend ابری ندارد.
- POST_NOTIFICATIONS: ورود کد Pairing و هشدار قطع اتصال.
- RECEIVE_BOOT_COMPLETED: تلاش برای بازیابی بعد از ریبوت.
