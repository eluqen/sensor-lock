# Sensor Lock 1.2.0

Official ELUQEN update for the Android application `com.eluqen.sensorlock`.

- Independent, direct Camera and Microphone controls.
- Explicit protection status for each sensor and full protection, with live state verification.
- Independently configured Quick Settings control for camera, microphone or both.
- Expanded Help and About and clearer pairing guidance in English, Persian and French.
- Better separation of local service health, pairing authorization and sensor state during connection recovery.
- Connection Status is displayed when repair is required, with a connection repair tool.
- ACCESS_NETWORK_STATE supports Wi-Fi checks during local pairing and recovery. No account, advertising, analytics, tracking or cloud backend.
