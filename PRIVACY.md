# Privacy Policy — Sensor Lock

Sensor Lock is designed to perform its core privacy controls locally on the Android device.

## Data collection

Sensor Lock does not collect or upload personal information, camera content, microphone recordings, contacts, location, advertising identifiers, analytics events or sensor-state telemetry.

The app has no account system, advertising SDK, analytics SDK or cloud backend.

## Network permission

The Android INTERNET permission is present because initial pairing and repair use Android's local ADB/TLS networking APIs to connect to the debugging service on the same device.

Sensor Lock does not configure a remote API endpoint for normal operation.

## External links

The About screen contains user-initiated links to the ELUQEN website, the public GitHub repository, Cafe Bazaar and the user's e-mail client for support.

These links open only when the user chooses them.

## Notifications

Notifications are used during initial pairing and when Sensor Lock detects that reconnection is required. A successful normal connection does not keep a permanent connected notification.
